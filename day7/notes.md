# Day 7 – Tiffin & Home Food Business Web Application

## 1. Day 7 Overview

Day 7 focuses on final project review, application testing, documentation verification, and preparation for project submission.

## 2. Objectives

- Review the complete project structure.
- Verify the homepage and dashboard.
- Check the registration and login pages.
- Test the meal plans and subscription features.
- Verify frontend and backend connectivity.
- Review project documentation and diagrams.
- Prepare the project for GitHub submission.

## 3. Project Structure

The project is organized into separate folders for frontend, backend, and daily documentation.

- `frontend/` – React and Vite application.
- `day3/` – Django backend application.
- `day1/` to `day7/` – Daily work and documentation, according to the project structure.

## 4. Frontend Review

The frontend is developed using React and Vite.

The following pages should be reviewed:

- Homepage
- Login Page
- Register Page
- Dashboard
- My Subscriptions
- My Orders, if implemented

Check that pages load correctly and navigation links open the intended routes.

## 5. Backend Review

The backend is developed using Python and Django.

The following items should be verified:

- Django development server starts correctly.
- API endpoints respond as expected.
- Database connectivity works.
- Registration and login requests are processed correctly.
- Authentication and error handling work as intended.

## 6. Main Features Review

### Meal Plans
Verify that available meal plans, descriptions, and prices are displayed correctly.

### Customer Accounts
Check the registration and login forms and their backend connectivity.

### Subscriptions
Verify subscription dates, quantities, prices, statuses, and available pause or cancellation actions.

### Dashboard
Check the dashboard layout and navigation to the available application modules.

### Orders and Delivery
Verify order and delivery features if they have been implemented.

## 7. Project Documentation

The project documentation should include:

- Introduction
- Problem Statement
- Aim and Objectives
- Functional Requirements
- Non-Functional Requirements
- System Modules
- Entity Relationship Diagram (ERD)
- Data Flow Diagram (DFD)
- User Interface Screenshots
- Testing Checklist
- Conclusion

## 8. Final Testing Checklist

1. Open the homepage.
2. Check the Login and Register pages.
3. Verify the Django backend.
4. Check database connectivity.
5. Open the Dashboard.
6. Test the My Subscriptions page.
7. Check navigation links.
8. Review the ERD and DFD.
9. Check for missing files and import errors.
10. Record any remaining issues before submission.

## 9. GitHub Review

Before pushing the project to GitHub:

- Check the current Git status.
- Review the files to be committed.
- Ensure sensitive credentials and `.env` files are not included.
- Avoid uploading virtual environment folders.
- Commit the verified project files.
- Push to the configured GitHub repository.

## 10. Day 7 Outcome

Day 7 records the final review and submission preparation activities for the Tiffin & Home Food Business Web Application.

Only features that have been tested successfully should be marked as completed.

## 11. Conclusion

The Tiffin & Home Food Business Web Application is designed to provide a convenient interface for exploring homemade meal plans and managing customer subscriptions. The final review should verify the implemented features, backend connectivity, database operations, documentation, and project repository before submission.
