# Day 6 – Tiffin & Home Food Business Web Application

## 1. Day 6 Overview

Day 6 focuses on testing the main application features, checking frontend and backend connectivity, reviewing navigation, and documenting the issues that need to be resolved.

## 2. Day 6 Objectives

- Test the homepage and dashboard.
- Verify customer registration and login pages.
- Check meal plan and subscription pages.
- Verify frontend and backend connectivity.
- Identify and document application errors.
- Review the project structure and prepare for final verification.

## 3. Frontend Testing

The frontend is developed using React and Vite.

The following pages should be checked:

- Homepage
- Login Page
- Register Page
- Dashboard
- My Subscriptions
- My Orders, if implemented

Verify that each page opens correctly and its navigation links work as expected.

## 4. Backend Testing

The backend is developed using Python and Django.

Testing activities include:

- Starting the Django development server
- Checking API responses
- Verifying registration and login requests
- Checking database connectivity
- Reviewing authentication errors
- Confirming that frontend requests reach the backend

## 5. Subscription Testing

The subscription module should be tested for:

- Displaying subscription details
- Showing start and end dates
- Displaying subscription price and quantity
- Checking the current subscription status
- Testing pause and cancellation actions
- Verifying that updated status is displayed correctly

## 6. Dashboard Testing

The dashboard should provide navigation to the main application features.

Verify that:

- The Dashboard page opens correctly.
- Meal Plans navigation works.
- My Subscriptions opens the subscription page.
- My Orders opens the intended orders page, if implemented.
- No missing-page or import errors occur.

## 7. Error Handling

The following issues should be checked and resolved where applicable:

- Django server connection errors
- Database authentication errors
- API authentication errors
- Missing React component imports
- Incorrect navigation paths
- Data not loading from the backend
- Subscription status not refreshing correctly

## 8. Testing Checklist

1. Open the homepage.
2. Open the Login page.
3. Open the Register page.
4. Start the Django backend.
5. Verify database connectivity.
6. Test the My Subscriptions page.
7. Test available subscription actions.
8. Open the Dashboard.
9. Verify the navigation links.
10. Record any remaining errors.

## 9. Day 6 Outcome

Day 6 documentation records the application's testing activities, important modules, and issues that require verification.

A feature should be marked as completed only after it has been tested successfully.

## 10. Next Steps

- Resolve remaining errors.
- Verify the main customer workflows.
- Review the project documentation.
- Check the project files before committing.
- Prepare the project for final review and submission.
