# User Stories

## 1. Admin/Owner User Stories

### US-01: Manage Customers

As an Admin/Owner, I want to create, view, edit and manage customer information so that I can maintain customer records.

### US-02: Manage Meal Plans

As an Admin/Owner, I want to create and manage daily, weekly and monthly meal plans so that customers can select suitable plans.

### US-03: Manage Subscriptions

As an Admin/Owner, I want to manage customer subscriptions with start date, end date, status and pricing so that subscriptions can be tracked properly.

### US-04: Manage Daily Orders

As an Admin/Owner, I want to view and manage daily orders generated from active subscriptions so that daily meal requirements can be managed.

### US-05: Manage Deliveries

As an Admin/Owner, I want to assign orders to delivery staff and monitor delivery status so that deliveries can be tracked.

### US-06: Manage Payments

As an Admin/Owner, I want to manage invoices, advances, pending payments and payment history so that financial records remain organized.

### US-07: View Reports

As an Admin/Owner, I want to view reports such as daily meal count, active subscribers, revenue, pending payments and delivery performance so that I can monitor the business.

---

## 2. Kitchen Staff User Stories

### US-08: View Daily Meal Quantity

As Kitchen Staff, I want to view the day's meal quantity so that I can prepare the required number of meals.

### US-09: View Daily Orders

As Kitchen Staff, I want to view daily orders and meal requirements so that I can prepare meals correctly.

### US-10: View Customer Meal Requirements

As Kitchen Staff, I want to view relevant meal options and dietary preferences so that meals can be prepared according to customer requirements.

---

## 3. Delivery Staff User Stories

### US-11: View Assigned Deliveries

As Delivery Staff, I want to view orders assigned to me so that I know which deliveries I need to complete.

### US-12: View Delivery Area

As Delivery Staff, I want to view deliveries grouped by area so that I can manage my delivery route efficiently.

### US-13: Update Delivery Status

As Delivery Staff, I want to update an order as delivered or not delivered so that the delivery status remains accurate.

### US-14: Access Delivery Information

As Delivery Staff, I want to view necessary delivery information and instructions so that I can deliver orders correctly.

---

## 4. Customer User Stories

### US-15: Register Account

As a Customer, I want to register an account so that I can use the tiffin service application.

### US-16: Login

As a Customer, I want to log in securely so that I can access my authorized features.

### US-17: Manage Profile

As a Customer, I want to manage my profile, address, delivery instructions and dietary preferences so that my information remains up to date.

### US-18: View Meal Plans

As a Customer, I want to view available meal plans so that I can choose a suitable plan.

### US-19: Subscribe to Meal Plan

As a Customer, I want to subscribe to a meal plan with a start date, end date and pricing so that I can receive meals regularly.

### US-20: View Subscription

As a Customer, I want to view my subscription status so that I know whether my subscription is active, paused or cancelled.

### US-21: Pause Service

As a Customer, I want to temporarily pause my service so that meals are not delivered during my unavailable dates.

### US-22: Resume Service

As a Customer, I want to resume my paused service so that I can continue receiving meals.

### US-23: View Daily Orders

As a Customer, I want to view my daily orders so that I know which meals are scheduled for delivery.

### US-24: View Payment History

As a Customer, I want to view my payment history and pending payments so that I can track my financial records.

### US-25: Provide Feedback

As a Customer, I want to provide ratings, complaints and meal feedback so that I can share my experience.

### US-26: Receive Notifications

As a Customer, I want to receive notifications about subscription renewal, daily delivery, payment reminders and pause confirmations so that I do not miss important information.

---

## 5. General User Stories

### US-27: Search Records

As an authorized user, I want to search records so that I can quickly find required information.

### US-28: Filter Records

As an authorized user, I want to filter records so that I can view relevant information easily.

### US-29: Responsive Application

As a user, I want the application to work properly on desktop, tablet and mobile devices so that I can access it from different devices.

### US-30: Validation Messages

As a user, I want clear validation and error messages so that I understand and correct invalid information.

---

## User Role Summary

| Role | Main Responsibilities |
|---|---|
| Admin/Owner | Customers, meal plans, subscriptions, orders, deliveries, payments and reports |
| Kitchen Staff | Daily meal quantities and order requirements |
| Delivery Staff | Assigned deliveries and delivery status |
| Customer | Profile, meal plans, subscriptions, pause/resume, payments and feedback |
